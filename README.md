# Haven

Haven is a multilingual conversation tool for people looking for guidance in a
potentially unsafe or difficult situation. It asks about what is happening and
provides simple, situation-specific suggestions, such as seeking medical,
legal, psychological, or emergency support.

Haven is a **demo and support-information tool**. It is not a replacement for
emergency services, a trained professional, or a local support organisation.
If someone is in immediate danger, contact the local emergency service first.

## What Haven can do

- Have a conversation in English, French, German, Italian, Spanish, Portuguese,
  Albanian, Turkish, Arabic, Bosnian, Croatian, or Serbian (Latin or Cyrillic).
- Help identify whether a situation may involve conflict or physical, sexual,
  psychological, or economic violence.
- Suggest practical next steps based on the information shared.
- Offer a quick-exit button that takes the browser to another website.

## Run Haven on a computer

These instructions are for Windows and assume that a project administrator has
provided access to the required language-model API key.

### 1. Install the prerequisites

Install:

- [Python 3.12 or newer](https://www.python.org/downloads/)
- [uv](https://docs.astral.sh/uv/getting-started/installation/) for the
  backend
- [Node.js](https://nodejs.org/) (the current LTS release) for the website

After installing, open **Command Prompt** and check that they are available:

```bat
python --version
uv --version
node --version
npm --version
```

### 2. Add the API key

Create a file named `.env` inside the `backend` folder:

```text
RCP_API_KEY=replace_with_the_key_provided_to_you
```

Keep this file private. Do not upload it to GitHub or share it in screenshots,
messages, or issue reports.

### 3. Install the project packages

From the project folder, run:

```bat
cd backend
uv sync
cd ..\frontend
npm install
cd ..
```

### 4. Start Haven

The easiest option is to double-click `start-dev.cmd` in the project folder.
Two command windows will open: one for the backend and one for the website.

Alternatively, open two Command Prompt windows.

In the first window:

```bat
cd backend
uv run uvicorn main:app --reload --port 8000
```

In the second window:

```bat
cd frontend
npm run dev
```

Open the address shown by the frontend window, normally:

<http://localhost:5173>

Keep both command windows open while using Haven. To stop the application,
close those windows or press `Ctrl+C` in each one.

## Using the website

1. Select a language from the language menu.
2. Describe the situation in your own words. Avoid names, addresses, or other
   information that could identify someone.
3. Read the response and follow only the suggestions that are safe and
   appropriate for the person concerned.
4. Use the quick-exit control if leaving the page quickly is necessary.

The conversation is intended to be supportive, not to make a legal or medical
decision. Information generated by the tool should be checked with a trusted
local professional or support organisation.

## If something does not work

### The backend window shows an API-key error

Make sure `backend\.env` exists, contains `RCP_API_KEY=...`, and that the key
is valid. Restart the backend after changing the file.

### The website cannot send a message

Make sure both windows are running. The website expects the backend at
`http://localhost:8000` and the chat endpoint at `/chat`.

### The page does not open

Check the frontend command window for the current local address. If port 5173
is already in use, use the alternative address printed by Vite.

## For project contributors

The project has two parts:

- `frontend/`: the React website and translations.
- `backend/`: the FastAPI service, conversation flow, evaluation rules, and
  response data.

Useful commands:

```bat
cd frontend
npm run build
```

The backend requires Python `3.12+`; its exact dependencies are recorded in
`backend/pyproject.toml` and `backend/uv.lock`.
